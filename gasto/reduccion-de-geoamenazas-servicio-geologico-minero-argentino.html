Reducción de Geoamenazas

Ministerio de Economía › Servicio Geológico Minero Argentino

El proyecto de Presupuesto 2027 pide $3.519 millones para Reducción de Geoamenazas (Servicio Geológico Minero Argentino).

Pedido para 2027$3.519 millonesProyecto de ley

¿Cómo cambió desde 2020?

Este programa cambió de nombre o se reorganizó en estos años, así que se muestra el gasto de todo el organismo (Servicio Geológico Minero Argentino). Descontada la inflación, lo pedido para 2027 para todo el organismo es 29% menos que lo que se gastó en 2023.
